slang-rhi examples

Interactive graphics using Slang and WebGPU. Open an example, click its canvas, and use the controls shown on screen. Press F1 to hide the overlay. Use the dropdown or F4 / Shift+F4 to switch examples without reloading.

SurfaceClear and present a window image. TriangleA vertex buffer and a graphics pipeline. ShaderToyCompute shaders, an ocean, and interactive input. RasterThe Slang logo, materials, shadows, and environment lighting. ParticlesA GPU simulation with interactive forces and indirect drawing.

Requires a WebGPU-capable browser on localhost or HTTPS. Shaders compile on first use, so initial loading may take a moment.

The native path tracer requires acceleration structures and ray tracing, which this WebGPU backend does not support.
