# RayQuery CTS adaptation manifest

This manifest fixes the selected set at **exactly 30** independently registered test scenarios.
They are semantic adaptations of the Apache-2.0
[Khronos VK-GL-CTS RayQuery suite](https://github.com/KhronosGroup/VK-GL-CTS/tree/main/external/vulkancts/modules/vulkan/ray_query);
the Vulkan harness, descriptor model, and shader-stage permutations are not copied.
The SPDX notices above preserve the copyright holders named by the selected upstream source
files.

The local shader uses the direct Slang/DXR equivalents:

- `rayQueryInitializeEXT` → `RayQuery.TraceRayInline`
- `rayQueryProceedEXT` → `RayQuery.Proceed`
- `rayQueryGenerateIntersectionEXT` → `RayQuery.CommitProceduralPrimitiveHit`
- `rayQueryConfirmIntersectionEXT` → `RayQuery.CommitNonOpaqueTriangleHit`
- `rayQueryTerminateEXT` → `RayQuery.Abort`
- Vulkan ray flags → the same-valued Slang/HLSL `RAY_FLAG_*` values
- Vulkan candidate/committed accessors → Slang `Candidate*`/`Committed*` methods

Expected values are authored in `test-ray-query-cts.cpp` from the CTS semantics and the
[DXR functional specification](https://microsoft.github.io/DirectX-Specs/d3d/Raytracing.html).
D3D12 output is therefore a second implementation under test, not the oracle.

## Deliberate exclusions

- Shader-stage permutations other than compute are redundant for a CPU/D3D12 inline-query
  semantics suite.
- Vulkan descriptor, pipeline-layout, sparse-binding, GPU-build, and array-of-pointers dimensions
  test Vulkan API behavior rather than DXR RayQuery semantics.
- OMM, position fetch, motion, cluster, sphere, LSS, and other extensions are outside the common
  DXR 1.1/CPU feature set used here.
- The stress cases retain the traversal-state invariant but use 32 primitives so they remain
  deterministic unit tests rather than importing CTS's conformance-scale workload.

## Reproduction

From the Slang integration root after building `slang-rhi-tests`:

```powershell
build\Debug\bin\slang-rhi-tests.exe -tc=ray-query-cts-*.cpu
build\Debug\bin\slang-rhi-tests.exe -tc=ray-query-cts-*.d3d12
```

Both commands currently report `30 passed, 0 failed`, with 1423 assertions per backend.
